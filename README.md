# Trilha da Pontuação

Jogo educativo digital sobre padrões da escrita e pontuação (ponto final, exclamação e interrogação), em 5 etapas.

## Como usar

Abra o `index.html` no navegador, ou publique pelo GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

## Estrutura

- `index.html` – estrutura da página
- `style.css` – estilos
- `script.js` – lógica e jogos

Usa Tailwind CSS (CDN) e Google Fonts, portanto precisa de internet.
