# Trilha da Pontuação

Jogo educativo web sobre pontuação e padrões da escrita, com várias etapas (minijogos) em sequência.

## Como usar

Abra o arquivo `index.html` em qualquer navegador moderno. Não precisa instalar nada.

> Requer internet para carregar o Tailwind CSS (CDN) e as fontes do Google Fonts (Fredoka e Comic Neue).

## Estrutura

```
trilha-da-pontuacao/
├── index.html      # Estrutura da página
├── css/
│   └── style.css   # Estilos
└── js/
    └── script.js   # Lógica dos jogos e sons (Web Audio API)
```

## Publicar no GitHub Pages

1. Envie os arquivos para um repositório.
2. Vá em **Settings → Pages**.
3. Em **Branch**, escolha `main` e a pasta `/ (root)`.
4. Salve. O link do jogo aparecerá em alguns minutos.
