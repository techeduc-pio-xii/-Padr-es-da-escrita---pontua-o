# Trilha da Pontuação

Jogo educativo web sobre pontuação e padrões da escrita, com 8 etapas (minijogos) em sequência.

## Como usar

Abra o `index.html` no navegador. Os três arquivos (`index.html`, `style.css` e `script.js`) precisam ficar **na mesma pasta**.

> Requer internet para carregar o Tailwind CSS (CDN) e as fontes do Google Fonts.

## Arquivos

- `index.html`: estrutura da página
- `style.css`: estilos
- `script.js`: lógica dos jogos e sons

## Publicar no GitHub Pages

1. Envie os 3 arquivos para a raiz de um repositório.
2. Em **Settings → Pages**, escolha o branch `main` e a pasta `/ (root)`.
